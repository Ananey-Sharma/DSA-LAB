DATA STRUCTURES AND ALGORITHM LAB

📘 About This Repository

This repository contains all laboratory experiments performed as part of the Data Structures and Algorithms (DSA) Lab – Semester II.
The lab focuses on implementing core data structures and algorithms using Python, applying them to real-world inspired problem statements such as e-commerce systems, transportation networks, ticketing systems, and optimization problems.
This repository documents our journey toward mastering algorithmic thinking and computational problem-solving.
